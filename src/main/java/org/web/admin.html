Игровые настройки
из 8
Сколько игроков должно загрузиться, чтобы матч начался автоматически (1–8). При 1 матч стартует даже с одиночным игроком.
из 64
Лимит одновременных игроков на сервере (2–64). Новые подключения отклоняются при заполненности. Не может быть меньше минимума для старта.
минут (1–120)
Текущее значение: —
В формате HEX (0–9, A–F, до 16 цифр). 0 или пусто — проверка отключена. Если задан — при логине отключаются клиенты с другим хешем.
Как применяются настройки
  • Минимум для старта — проверяется при загрузке каждого игрока: как только готовых становится достаточно, матч стартует автоматически (и по истечении таймаута загрузки, если готовых хватает).
  • Максимум игроков — действует сразу: при заполненном сервере новые клиенты не смогут войти. Уже подключённые игроки не отключаются.
  • Время матча — используется в следующем матче. Если матч идёт прямо сейчас, его таймер перезапускается на новую длительность (удобно, чтобы продлить или сократить текущий матч).
  • Хеш соединения — в настройках хранится как HEX, на сервере преобразуется в long. 0 — проверка выключена. Если задан — при логине сравнивается с hash клиента, несовпадающие отключаются.
  • Сохранение — настройки пишутся в admin_config.properties и переживают рестарт сервера. База данных для них не нужна.
Уменьшение максимума ниже текущего онлайна не выгоняет игроков — просто новые не войдут, пока не освободится место.
